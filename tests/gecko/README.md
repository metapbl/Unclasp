# gecko 자동 테스트 (Firefox ESR·토르)

`npm run test:gecko`. 빌드한 xpi 를 임시 프로필의 Firefox ESR 과 토르에 임시 설치해 PRD F1~F9 인수 기준을 돌린다 (D040). 실행 파일 경로는 `UC_FIREFOX`·`UC_TOR`, 없으면 그 브라우저는 건너뛴다. 도우미는 `gecko.mjs`.

Chrome 쪽(`tests/e2e`)의 특성 테스트는 엔진과 무관한 세부 동작이라 옮기지 않았다. 여기서는 인수 기준만 두 브라우저에서 본다.

## 실기기로 확인할 것 (자동화가 안 되는 항목)

번호 목록으로 예/아니요와 본 것을 답한다. 토르와 Firefox 에서 각각 확인한다.

1. 단축키 Alt+Shift+O(팝업)·C(골라 숨기기)·X(진단)·Z(배너)가 동작한다. accesskey 가 겹치는 페이지(예: 위키백과)에서는 페이지가 먼저 받는 것이 한계이고, 툴바 아이콘으로 연 팝업에서는 동작한다 (D059) — WebDriver 는 브라우저 단축키를 누르지 못한다
2. 확장을 새로 고친 직후 팝업을 연 적 없는 탭에서 Alt+Shift+X 로 진단이 켜진다 (F6 다섯째) — 단축키라서
3. 툴바 아이콘을 눌러 연 팝업이 그 탭의 사이트를 보여 준다 — 테스트는 팝업 페이지를 탭으로 연다
4. 덮개가 있는 실제 사이트에서 선택기로 고른 요소가 클릭된다 (F7) — 외부 사이트에 접속하지 않는다
5. 우클릭 해제를 켜면 브라우저 메뉴가 실제로 뜬다 (F4 첫째) — 테스트는 페이지 처리가 안 도는 것까지만 본다
6. about:config 서명 검사 해제 후 xpi 영구 설치, "사생활 보호 창에서 실행" 허용, 브라우저를 다시 켜도 설정이 남는다 — 테스트는 임시 설치에 권한을 코드로 준다
7. 백업 "파일로 저장" 이 저장 위치를 묻거나 내려받기 폴더에 저장된다 — 테스트는 묻지 않게 설정한다
8. 평소 숨김이 실제 사이트에서 페이지가 뜰 때 배너를 잠깐 보이지 않고, 무한 스크롤처럼 DOM 이 계속 바뀌어도 텍스트 규칙 숨김이 다른 요소로 옮겨 가지 않는다 (F10 넷째, D044) — Firefox·토르는 배경을 거쳐 비동기로 넣고, 외부 사이트에 접속하지 않는다
